# API Reference (v1)

Base: `/api/v1/`. Auth: `Authorization: Token <token>` from `POST /api/v1/auth/login/`. All list endpoints are paginated (`{count, results}`). Errors are consistent: `{"error": {"code": <http>, "message": "...", "details": ...}}`. Every response carries an `X-Request-ID` header.

| Method | Path | Who | Notes |
|---|---|---|---|
| POST | `/auth/login/` | anyone | Returns token + user |
| GET | `/auth/me/` | authenticated | Current user |
| GET/POST | `/users/` | admin only | Organization-scoped |
| GET/POST | `/documents/` | authenticated | POST = multipart upload (field `file`), org-scoped |
| GET/DELETE | `/documents/{id}/` | owner org only | Cross-tenant IDs return 404 (no existence leak) |
| GET | `/documents/{id}/chunks/` | owner org only | Extracted chunks with page numbers |
| POST | `/documents/{id}/reprocess/` | owner org only | Re-queue processing |
| POST | `/documents/{id}/reviews/` | authenticated | Body: `{"policy_version_id": "..."}`. 400 if document not completed |
| GET | `/reviews/`, `/reviews/{id}/` | owner org only | Includes result + findings + evidence |
| GET | `/findings/?severity=&category=&status=` | owner org only | Filterable |
| POST | `/findings/{id}/approve/ | reject/ | escalate/ | edit/` | reviewer/admin only | Body: `{"comment": "...", "edited_title": "...", "edited_description": "..."}`. Uploaders get 403 |
| GET/POST | `/policies/` | authenticated | POST creates policy + first version (`version`, `rules`, `checklist`) |
| POST | `/policies/{id}/add_version/` | authenticated | Adds a new immutable version |
| GET | `/audit-events/` | authenticated | Organization-scoped, newest first |
| GET | `/evaluation-runs/` | authenticated | Stored evaluation run metrics |
| GET | `/dashboard/stats/` | authenticated | Real counts for the caller's organization |
| GET | `/health/live/`, `/health/ready/` | public | No secrets or infra details; ready checks DB connectivity only |

OpenAPI: `/api/schema/` and Swagger UI at `/api/docs/` (generated by drf-spectacular from the live code).
